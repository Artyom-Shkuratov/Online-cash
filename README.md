# Онлайн-касса 

## Описание

Проект реализует простую модель онлайн-кассы на Python.  
Программа позволяет добавлять и удалять товары из чека, считать сумму покупки с учётом скидки, рассчитывать НДС, а также получать номер телефона покупателя и дату совершения покупки.

Код написан с использованием ООП.

## Функциональность

Класс `OnlineSalesRegisterCollector` реализует следующие функции:

- добавление товара в чек с проверкой валидности названия;
- удаление товара из чека;
- подсчёт общей суммы товаров в чеке (со скидкой, если товаров больше 10);
- расчёт НДС по ставке 20% и 10%;
- подсчёт общей суммы НДС по чеку;
- валидация и форматирование номера телефона покупателя;
- получение текущих даты и времени.
